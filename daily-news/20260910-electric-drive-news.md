## 1. 采埃孚（ZF）同轴电驱系统获两家国内车企项目定点：基于 SELECT 电驱平台，800V 版本最高 300kW / 5000N·m，镁合金壳体、体积优化 25%、系统效率 >93.5%、NVH 降低 3~5 分贝

**分类**：产品发布 / 商业动态（国际Tier1 800V同轴电驱总成获国内规模化定点）
**摘要**：采埃孚（ZF）宣布其同轴电驱系统先后获得两家国内领先汽车制造商的项目定点，标志着采埃孚电驱业务在中国新能源汽车市场实现规模化突破；该系统基于SELECT电驱平台打造，800V平台版本采用高度集成化设计，可提供最高300kW电驱功率和5,000N·m峰值扭矩，支持升压充电、充配电及电子限滑等功能拓展，产品采用同轴构型及镁合金壳体设计，整体体积优化25%，系统综合效率超过93.5%，NVH噪声较传统方案降低约3至5分贝。
**来源**：[Marklines（2026-09-02）· 采埃孚同轴电驱系统获两家国内车企项目定点](https://www.marklines.com/cn/news/350188)
**发布时间**：2026-09-02（处48h-192h核心时效窗口；国内规模化定点里程碑宽限收录）
**相关企业/机构**：采埃孚（ZF Friedrichshafen AG，德国，全球汽车传动与底盘系统Tier1）
**技术亮点**：

- 核心量化参数：①800V平台版本最高电驱功率=**300 kW**；②峰值扭矩=**5,000 N·m**；③系统综合效率=**>93.5%**；④整体体积优化=**25%**；⑤NVH噪声较传统方案降低=**约3~5 dB**

- 平台基础：基于采埃孚**SELECT电驱平台**打造，采用**高度集成化设计**

- 结构设计：①**同轴构型**（电机、逆变器、减速器同轴布置）；②**镁合金壳体**（轻量化）

- 功能拓展：支持**升压充电**、**充配电**、**电子限滑**（eLSD）等功能拓展

- 技术阶段：**已获两家国内车企项目定点**（待量产，定点里程碑已达成）

- 相比行业方案：采埃孚SELECT平台同轴电驱以"300kW/5000N·m+镁合金壳体+同轴构型"实现体积-25%、效率>93.5%、NVH -3~5dB的综合指标，区别于传统平行轴电驱的NVH与布置劣势；两家国内车企定点标志国际Tier1 800V电驱在中国市场从"技术展示"进入"规模化量产定点"阶段，与本期第3条博世商用车800V刚性电驱桥、第4条博格华纳iDM共同构成"国际Tier1 800V电驱桥规模化落地"的产业图景

- 产业意义：800V高压平台从乘用车向商用车、从单一部件向系统总成渗透的背景下，采埃孚以同轴电驱+镁合金壳体的轻量化集成方案获国内规模化定点，体现国际Tier1在800V电驱总成赛道的平台化与规模化优势；升压充电、充配电、电子限滑的功能拓展则反映电驱总成从"动力输出"向"整车能量管理+底盘控制"延伸的趋势

**相关企业/机构**：湖南中车时代电驱科技有限公司（中车时代电气股份有限公司子公司，中国中车集团，新能源汽车电驱零部件及系统自主研发产业化平台，株洲/无锡/长春/柳州/印尼生产基地）
**技术亮点**：

- 量产项目并行（2026-09-03至09-09密集招标）：①**M220-90KW-量产**（毕普拉斯采购，9/9）；②**WL-P1-量产-铁芯**（9/4）；③**E260电机壳体-低压压铸-批产**（9/3）；④**BE12-量产-VAVE铁芯**（9/6）；⑤**XM01-永磁体量产**（9/8）；⑥北汽BE12VAVE量产减速器（9/8中标）

- 相比行业方案：54槽短距扁线定子以"两相并联支路反向绕制+跨距y/y+1按2:1比例+跨距y-2跨层"的绕组排布，实现线型少、插线简单并消除支路不对称，区别于传统整距48/54槽扁线绕组（跨距5+7或全6）的支路电势不平衡与环流问题；中车时代电驱作为轨交 heritage 延伸的第三方电驱供应商，以"专利绕组结构创新+200万台套年产能+多项目量产招标"双线推进，在扁线电机赛道追赶弗迪动力、汇川联合动力等头部

- 产业意义：扁线电机作为新能源乘用车驱动电机主流方案（渗透率超60%），其绕组结构创新直接关系槽满率、效率、NVH与制造良率；中车时代电驱54槽短距扁线定子专利以"支路对称消除"为核心创新点，叠加年产能超200万台套与M220-90KW等多项目量产，体现国内第三方电驱供应商在扁线电机从"结构创新"到"规模化量产"的完整能力

## 4. 博格华纳（BorgWarner）下一代集成驱动模块（iDM）获全球 OEM 定点：三合一同轴驱动（eMotor + 同轴减速箱 + GenIV 逆变器含 Viper D 功率开关），油冷电机，2027 年量产

**分类**：产品发布 / 商业动态（国际Tier1下一代集成电驱总成定点）
**摘要**：博格华纳（BorgWarner）2026年8月4日宣布获得一家全球OEM的下一代集成驱动模块（iDM）项目定点，量产预计于2027年开始；该方案采用博格华纳最新的三合一集成同轴驱动系统，将先进eMotor、减速箱与全集成GenIV逆变器整合于紧凑高性能封装内，GenIV逆变器采用博格华纳最新一代Viper D功率开关技术以降低开关损耗、提升电流能力，系统还配备下一代高度集成同轴减速箱（紧凑布局提升整车布置灵活性）、油冷电机（满足严苛性能要求）以及满足严苛安全目标与法规要求的集成驻车系统，采用积木式软硬件集成策略实现高度可扩展平台。
**来源**：[PR Newswire（2026-08-04）· BorgWarner Wins Major Program with Next-Generation Integrated Drive Module Technology](https://www.prnewswire.com/news-releases/borgwarner-wins-major-program-with-next-generation-integrated-drive-module-technology-302841154.html)
**发布时间**：2026-08-04（处48h窗口外，含GenIV逆变器+Viper D功率开关等关键技术细节，国际Tier1电驱总成里程碑宽限收录）
**相关企业/机构**：BorgWarner Inc.（博格华纳，美国密歇根州奥本山，全球动力驱动系统Tier1）
**技术亮点**：

- 系统架构：**三合一集成同轴驱动系统**=①先进**eMotor**（驱动电机）；②**减速箱**；③全集成**GenIV逆变器**

- GenIV逆变器核心：采用博格华纳最新一代**Viper D功率开关技术**——**降低开关损耗**、**提升电流能力**，从而提升整体eDrive系统效率

- 电机冷却：**油冷电机**（oil-cooled motor），满足严苛性能要求

- 减速箱：**下一代高度集成同轴减速箱**，紧凑布局提升整车布置灵活性

- 驻车系统：**集成驻车系统**，满足严苛安全目标与法规要求
